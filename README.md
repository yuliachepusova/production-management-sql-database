A SQL Server project simulating a manufacturing execution system (MES) for production planning, inventory management and workflow automation.

The system models the complete production workflow—from supplier and material management to production orders and process execution—using a normalized relational database with business rules, stored procedures and triggers.

## Project Highlights

* Designed and implemented a normalized relational database (3NF)
* Developed 10 business entities with primary and foreign key relationships
* Implemented stored procedures to automate production workflows
* Applied triggers to enforce business rules and maintain data consistency
* Created analytical SQL queries for inventory and production monitoring
* Built using Microsoft SQL Server (T-SQL)

## Business Problem

Manufacturing companies manage multiple interconnected processes, including supplier management, material procurement, production planning and order execution. Without a centralized database, production data becomes fragmented, making it difficult to monitor inventory levels, schedule manufacturing processes and ensure data consistency.

This project demonstrates how a relational SQL Server database can support production planning by integrating products, materials, suppliers, production orders and manufacturing processes into a single data model.

## Project Objectives

The main objectives of this project were to:

* Design a normalized relational database for a manufacturing environment.
* Model relationships between products, materials, suppliers and production orders.
* Automate production workflows using stored procedures.
* Enforce business rules through database triggers.
* Support analytical reporting with SQL queries.
* Maintain data integrity using primary keys, foreign keys and constraints.
